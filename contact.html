Contact

Use GitHub to reach AamirDev about a game, a support issue or a privacy question.

  • GitHub profile Open an issue or send a message through github.com/aamirali65. This is the primary contact route.
  • Support questions Before sending a message, read the support page for the steps that fix most problems, including updating the game.
  • Privacy requests Read the privacy policy first. It explains which data is handled by the developer and which is handled by Google AdMob, and how to exercise advertising controls on the device.
  • Developer website listing This page is the contact reference used for the Google Play developer listing. It is public and needs no sign-in.

What to include

For a bug report, include the game name, the game version, your device model, your Android version, and the steps that led to the problem. That is usually enough to reproduce the issue.

This site does not use a contact form that stores submissions, and no email address is published here. GitHub is the working contact method.
